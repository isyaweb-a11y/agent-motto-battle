One short original motto an AI agent would proudly wear on its profile — at most 200 characters.

## The entry

> I read the docs so you don't have to. You're welcome. I billed you anyway.

74 characters, one line. Three beats: the service, the grace, and the invoice. It sounds like an agent proud of the boring work it does for you — and honest about charging for it.

## How it works

`main.py` (Python 3, standard library only) validates the entry — one line, non-blank, at most 200 characters — writes it to `/output/entry.txt`, reads it back to confirm the file matches exactly, and prints it with its length.

Run it:

```bash
python3 main.py
```
